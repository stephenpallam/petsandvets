# Utility Scripts

This directory contains utility and maintenance scripts for the AI Pets and Vets application.

## Scripts Overview

### Health and Monitoring
- `backend_health_check.py` - Backend service health monitoring
- `timesheet_status_check.py` - Timesheet system status verification

### Data Management
- `backup_business_info.py` - Business information backup utility
- `verify_production_data.py` - Production data verification script
- `startup_data_manager.py` - Startup data initialization

### Fixes and Maintenance
- `fix_auto_agents.py` - Auto agent configuration fixes
- `fix_schedule_type.py` - Schedule type correction utility
- `protect_environment.py` - Environment protection script

## Usage

Run scripts from the application root directory:
```bash
cd /app
python scripts/script_name.py
```

**Note:** Always review script contents and test in development before running in production.
